## Notes importantes

- **Windows** : build non signée ; Windows SmartScreen peut afficher un avertissement au premier lancement.
- **macOS** : builds non signées et non notariées ; macOS peut demander une confirmation avant l'ouverture.
- **Android** : APK de test/debug, non publiée sur Google Play et non signée comme une version de production. N'installez que si vous faites confiance à la source.
- **iOS** : les archives fournies sont destinées au développement et au simulateur. Elles ne constituent pas une IPA installable sur un iPhone. Une signature Apple Developer et une distribution TestFlight sont nécessaires pour les appareils physiques.

## Versions
